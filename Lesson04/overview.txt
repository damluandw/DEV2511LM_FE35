1. Cách sử dụng CSS 
    - trên thẻ HTML - style
    - trong file HTML - <style></style>
    - ngoài file HTML - <link href= "đường_dẫn_file/tên_file.css"> </link>
2. Các cách tương tác CSS với thẻ HTML
    - tương tác thông qua tên thẻ HTML - tên_thẻ_HTML
    - tương tác thông qua tên id của thẻ HTML - #tên_id
    - tương tác thông qua tên class của thẻ HTML - .tên_class
    - tương tác thông qua tên thuộc tính (attr) của thẻ HTML - [tên_attr]
3. Một số bộ chọn 
    - * : chọn toàn bộ file HTML (reset CSS)
    - tag01 tag02
    - tag01>tag02
    - tag01, tag02
    - tag01 + tag02
    - tag01 ~ tag02
    - :hover
    - :after, before
    -...
4. Cấp độ ưu tiên trong CSS
    - CSS viết sau được ưu tiên sử dụng
    - !important -> tên_id -> tên_class-> tên_attr -> tên_thẻ_HTML
    - bộ chọn càng gần hoặc càng chi tiết thì càng được ưu tiên sử dụng

5. Thuộc tính CSS - Giá trị thuộc tính
    - display: block,hidden,flex,...
    - font -(size,family,weight,...) : ...
    - color: tên_màu/RGB/#hệ_hex
    - background -(image,color,...):....
    - margin/padding: giá_trị +đơn_vị_đo
    - (min/max)- width/height: giá_trị +đơn_vị_đo
    - postion: fixed/rela../absolute,...
    - border (....): size kiểu_đường_bo màu_sắc 
    - border-radius: giá_trị_đường_bo
    - content: '' (đi với :after/before)
    -...
